О проекте

ShopProject — учебный интернет-магазин, разрабатываемый в рамках дисциплины «Фронтенд и бэкенд разработка». Проект развивается от простого HTML-каркаса до многостраничного сайта с формой заявки, модальным окном и БЭМ-структурой CSS.

Цели проекта

  • отработать семантическую HTML-разметку;
  • освоить методологию БЭМ;
  • применить Flexbox и CSS Grid;
  • подключить JavaScript для интерактивности;
  • подготовить проект к адаптивной вёрстке.

Этапы разработки

  1. Создание Git-репозитория и публикация на GitHub Pages.
  2. HTML-каркас и базовые CSS-стили.
  3. Форма заявки, модальное окно и валидация.
  4. CSS-переменные и состояния интерфейса.
  5. Многостраничная структура сайта.
  6. Flexbox-навигация и Grid-раскладка.
  7. Рефакторинг CSS по методологии БЭМ.

Планы развития

В следующих версиях проекта появятся адаптивная вёрстка, тёмная тема, корзина, страница товара и интеграция с backend.
